# Team Working Agreement and Role Guide

## Team Working Agreement

### Communication
- Team members shall respond to project-related messages within 24 hours.
- Important updates shall be communicated through the team's agreed platform.
- Questions and blockers should be raised as soon as possible.

### Meetings
- Attend scheduled sprint meetings.
- Participate actively in sprint planning, reviews, and retrospectives.
- Be prepared to provide progress updates during discussions.

### Source Control
- Work must be committed to a feature branch.
- Changes must be submitted through a Pull Request (PR).
- Code should not be merged directly into the main branch.

### Quality Standards
- Test changes before creating a PR.
- Follow agreed coding standards.
- Keep documentation updated when features change.

---

# Definition of Done (DoD)

A task is considered Done when:

- Feature implementation is complete.
- Acceptance criteria are satisfied.
- Testing has been performed.
- No critical defects remain.
- Documentation has been updated.
- Pull Request has been reviewed and merged.
- Feature is deployable.

---

# Team Roles and Responsibilities

## Scrum Master

Responsibilities:
- Facilitate sprint planning.
- Monitor sprint progress.
- Remove impediments and blockers.
- Maintain sprint documentation.
- Lead sprint reviews and retrospectives.

## Developer

Responsibilities:
- Implement assigned features.
- Perform unit testing.
- Fix defects.
- Participate in code reviews.
- Update technical documentation.

## Database Administrator (DB Admin)

Responsibilities:
- Create and maintain database structures.
- Manage migrations and seed data.
- Optimize database performance.
- Support data validation and backups.

## Tester

Responsibilities:
- Create test plans and test cases.
- Execute manual and automated tests.
- Report defects.
- Verify bug fixes.
- Support acceptance testing.

## UI/UX Designer

Responsibilities:
- Create wireframes and mockups.
- Review interface usability.
- Ensure design consistency.
- Provide design assets and handoff notes.

---

# Team Expectations

- Respect deadlines and commitments.
- Collaborate professionally.
- Communicate blockers early.
- Support teammates when needed.
- Focus on delivering sprint goals.
