# Repository Setup

## Branch Strategy

- main
- develop
- feature/* branches

## Pull Request Rules

- Every change must be submitted through a Pull Request.
- PR must include a description of changes.
- At least one review is required before merge.

## Issue Template

### Bug Report
- Description
- Steps to Reproduce
- Expected Result
- Actual Result

### Feature Request
- Description
- Acceptance Criteria
- Priority

## Branch Protection

- Prevent direct commits to main
- Require PR before merge
- Resolve conversations before merge
